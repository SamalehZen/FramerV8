## 2026-08-08 - Keyboard Accordion Navigation and ARIA Accessibility
**Learning:** Accordion lists implemented via standard div grids/lists lack essential keyboard indicator visual feedback and ARIA states, making it hard or impossible for screen reader or power users using only the keyboard to navigate them correctly. Adding standard ARIA attributes (`aria-expanded`, `aria-controls`, `role="region"`, `aria-labelledby`) coupled with high-contrast `focus-visible:ring-2` outline states significantly enhances overall UI accessibility.
**Action:** Always provide robust keyboard focus indicators (e.g. `focus-visible:ring-2 focus-visible:ring-navy focus-visible:ring-offset-2`) and complete ARIA attributes whenever building accordion controls, drawers, modals, or menu toggles. Avoid layout shift during focus state display by using negative margins and positive padding on elements.
