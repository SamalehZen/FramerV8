## 2025-02-18 - Accordion Semantics and Keyboard Target Polish
**Learning:** Standard interactive accordion elements often miss critical WAI-ARIA labels (`aria-expanded`, `aria-controls`, `role="region"`, `aria-labelledby`) and visible high-contrast keyboard focus feedback, causing significant barriers for screen-reader and keyboard users. Additionally, adding focus outlines directly to container elements or narrow text buttons can introduce layout shifts or visual crowding.
**Action:** When designing or refactoring accordion-style components, always implement semantic ARIA controls and high-contrast focus rings. Apply negative horizontal margins with corresponding positive padding (`px-3 -mx-3`) on full-width buttons inside padded containers to expand the click/focus target area, prevent visual overlap, and maintain exact alignment without layout shifts.
