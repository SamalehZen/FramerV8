## 2026-07-29 - Preventing Layout Shift from Keyboard Focus Rings on Accordions
**Learning:** Adding standard high-contrast keyboard focus outlines or rings (`focus-visible:ring-2`) to block or flex elements in tight components can inadvertently cause visual layout shifts or ugly clipping if parent elements have custom padding or background cards. By pairing focus-visible states with symmetric padding and negative margins (such as `px-3 -mx-3`), the trigger area is subtly enlarged without shifting any adjacent visual elements, drawing a perfectly centered and balanced focus ring around the target text.
**Action:** When designing focus indicators for nested interactive list components (like accordions or tabs), always pair focus rings with rounded containers and negative horizontal margins + matching horizontal padding (`px-[X] -mx-[X]`) to preserve pixel-perfect alignment.
