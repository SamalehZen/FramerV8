## 2025-02-14 - Keyboard Navigation and ARIA Compliance for Clean Tailwinds Accordions
**Learning:** In custom interactive components utilizing Tailwind and Framer Motion transitions (such as accordion sliders and mobile menu collapsibles), standard focus outlines can look clipped or break visual spacing. By utilizing relative positioning with custom horizontal padding and matching negative margins (`px-3 -mx-3`), we can construct custom high-contrast focus rings around interactive triggers that do not impact layout spacing or shift visual structure whatsoever. Additionally, adding comprehensive keyboard navigation (ArrowUp, ArrowDown, Home, End) on interactive lists vastly improves screen-reader accessibility and lowers keyboard interaction overhead.
**Action:** When wrapping groups of interactive components (like accordion triggers), always apply non-disruptive `focus-visible` rings with matching margins/padding, ensure W3C-compliant ARIA state indicators (`aria-expanded`, `aria-controls`, `role="region"`), and implement keydown event handlers for keyboard navigation.
