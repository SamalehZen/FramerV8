## 2025-05-18 - Accordion ARIA & Keyboard Accessibility
**Learning:** Accordion UI components require clear ARIA semantics (`aria-expanded`, `aria-controls`, `role="region"`, `aria-labelledby`) and distinct `focus-visible` focus rings so keyboard and screen reader users can navigate and understand collapsible content sections easily.
**Action:** Always verify collapsible headers/buttons have matching panel IDs, explicit ARIA state linkage, hidden visual-only icons (`aria-hidden="true"`), and high-contrast `focus-visible` ring styling.
