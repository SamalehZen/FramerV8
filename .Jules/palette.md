## 2025-05-18 - Accordion Semantics and Inset Focus Rings
**Learning:** Collapsible accordion buttons enclosed inside padded cards can have their focus rings clipped if default browser outlines or negative offsets are used. Providing explicit `id`, `aria-expanded`, and `aria-controls` linked to an expandable panel with `role="region"` and `aria-labelledby` ensures screen readers announce disclosure state changes accurately. Additionally, combining `focus-visible:ring-2 focus-visible:ring-navy focus-visible:ring-inset` on the trigger button gives distinct, high-contrast keyboard focus feedback without shifting or clipping card layouts.
**Action:** Always link accordion trigger buttons with corresponding panels using explicit ARIA relationships (`aria-controls`, `role="region"`, `aria-labelledby`) and use inset focus rings (`focus-visible:ring-inset`) on padded container-bound trigger buttons.
