## 2026-11-10 - Accordion Card Focus Indicators & W3C ARIA Semantics
**Learning:** In card-styled accordion lists where triggers are nested within rounded container cards, applying standard focus rings directly on the button cuts off or creates visual awkwardness against the rounded card container. Using `focus-within:ring-2 focus-within:ring-navy` on the outer card container with `focus:outline-none` on the button trigger cleanly encloses the full card component without clipping, alongside standard W3C ARIA accordion attributes (`aria-expanded`, `aria-controls`, `role="region"`, `aria-labelledby`).
**Action:** For card-based interactive widgets (accordions, expandable cards), delegate focus styling to the parent card using `focus-within` and pair it with explicit ARIA relationship IDs.
